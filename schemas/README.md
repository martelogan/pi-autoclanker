# schemas

Place public JSON schemas and other machine-readable contract files for the
realized project here.

- `pi-autoclanker.config.schema.json`: wrapper session config.
- `pi-autoclanker.proposals.schema.json`: local proposal mirror.
- `clankerbench.pipeline.schema.json`: generic staged benchmark manifest.
- `clankergraph.schema.json`: portable evidence/belief/benchmark/context graph artifact.
